# 反例

> **一条反例比十条正确案例更能纠正一个模型。**

## 收什么

- **「本来以为 X，结果 Y」**：一条就够，附当时的原话/记录（匿名）。
- **越具体越值钱**：别写「这方法不行」，写「某天、某场景、某一步，我以为会 A，实际出了 B」。

## 格式

| 反例 | 原以为 | 实际 | 出处/原文 |
|---|---|---|---|
| 001 | 拿 4/5 分当视频钩子 | 陌生人根本不关心分数，只问能不能装/用 | 盲测记录（见 `../否定/001_...`） |
## 怎么用：照见自己

- **反例不是用来点名批评谁**，是给你自己照镜子：**「我有没有犯这个错？」**
- **对得上 → 你大概率踩过；对不上 → 先别急着信自己的那条判断，再回头看。**
- **评价只有两票**：正确 / 错误。**投「错误」必须附这条反例本身**，否则不算数。
- **附了反例也要筛**：先筛「反例站不站得住」，站得住才进库——**筛选的过程就是学习。**

- **评价也匿名**：只投票/留反例，不写你是谁。
