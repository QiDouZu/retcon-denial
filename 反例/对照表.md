# 反例对照表（一一对照：过程错误 → 真正结果）

> **反例本身只是「过程中的错误」；真正结果要逐条对照。**
> 这页把库里每条反例对一遍账：**错在过程哪一步 → 拿什么结果对照 → 判定（对/错/悬）**。

## 对照纪律

- **每条错误都拿「后来的真实结果」来对**——不是对「我觉得」。
- **过程错 ≠ 结果错**：过程走了弯路、但结果恰好对的，标**「对（过程错）」**——那也是反例。
- **判定三档**：塌（结果证明错）· 悬（还没结果打脸）· 对（虽然过程错，结果对）。
- **对照看全程**：过程错在「哪一步」要对得上——只对头尾的对照，不算数。
- **判定映射三态**：**塌 → 曾经（反）**；**悬 → 猜测（中）**；**对 → 当前（正）**。

## 从审美课题来的五条，怎么用

这五条**全是审美发现「好在哪」时缺的那一块**——逐条照自己：**你上一次判断「哪里好」，是看到了好在哪，还是只看到「像」？**
