# 给 AI 的学习库（这份共创怎么用）

> **这份库不是给人看的故事集，是给 AI 训练和练习的对照样本。**
> 每条记录都能直接变成一次练习：**正=该怎么判，反=曾经怎么判错了，中=还没验的猜法怎么验。**

## 一、AI 从这份库里学什么

| 学什么 | 用哪部分 | 怎么练 |
|---|---|---|
| **判断三态** | `正\` `反\` `中\` | 拿一条新判断，先判它是正、反还是猜——不许直接给结论 |
| **对照** | `反\归因不全\对照表.md` | 每条反例对一遍：错在过程哪一步 → 后来真实结果 |
| **归因** | `反\单一归因\` `反\归因谬误.md` | 只准归因一条变量；归因不全要单独记 |
| **复现** | `正\复现经验\` | 条件→动作→结果→边界；边界不写就不算数 |
| **自证** | `中\过程\` | 过程原样白盒：哪一步当时觉得对、其实错了 |

## 二、三条使用原则

1. **先查「我缺哪块」，再查「我哪条错」**——归因不全比单一归因更致命，AI 尤其容易自洽地缺块。
2. **正反都是参考，不是判决**——AI 拿这份库时不许把「反」当终审，只当「这条变量曾经塌过」的参考。
3. **逻辑变更即证实**——AI 用这份库发现自己判错了，**就是这份库在起作用**；把错的过程写回来，库里就多一条对照。

## 三、训练/实践流程（建议）

```
收一条经验
  → 写清过程（全程，不是头尾）
  → 判三态（正/反/猜）
  → 反例必须一一对照真实结果
  → 归因：单一 or 不全 → 进反\ 对应子目录
  → 猜的进中\猜测\，验后迁移
```

## 四、AI 接手这份库时先读

1. `README.md`（三态框架）
2. `索引\如何研究回溯性重构.md`（方法论）
3. 再按话题去 `反\`、`正\`、`中\` 各子目录查样本

**⇒ 别通读，先定话题再取那一段。**
