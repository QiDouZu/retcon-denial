# 学习过程（原样开源，让人验证我是对是错）

> **这是把「我怎么想的」摊开：不是结论展，是过程展。**
> 你看完可以回答一句：**「你这里推错了」**——**否定我的过程，比复述我的结论有用。**

## 为什么开这个

- **结论好懂，过程才见真伪**：只说「审美找联系与闪光点」，你没法验证；说「我当时怎么量的、哪一条没证据」，你就能挑错。
- **让别人的否定进得来**：过程白盒 → 有人能指「这步跳了」「这数据不支撑这结论」→ **学习是我跟你们一起完成的。**

## 记录格式（每段过程一条）

| 项 | 填什么 |
|---|---|
| **原判断** | 我当时判断什么（原话可引，匿名） |
| **依据** | 拿什么推的（数据/案例/感觉都行，**感觉要标明是感觉**） |
| **哪步不清楚** | 从依据到判断，中间断在哪 |
| **怎么推翻我** | 什么证据出现就该推翻 |
| **现在状态** | 立着 / 悬着 / 塌了 |

## 已开的过程

- **001 审美**（见 `../原初/001_审美不是判断美丑.md`）：判断 = 闪光点（少）+ 联系（那条看不见的线）；**其中「温柔靠糙」悬着，等反例。**
- **002 视频钩子**（见 `../否定/001_4分当钩子_陌生人不关心分数.md`）：判断 = 数字当钩子；**塌了**——陌生人不关心分数，只关心能不能用。

## 规则

1. **过程也匿名**：不写身份，写「这类判断」。
2. **悬着的写悬着**：不装明白，标证据和猜。
3. **被推翻不删**：标「已推翻 + 谁/什么推翻的」——**那是最值钱的一行。**
