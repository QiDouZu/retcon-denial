# 中：猜测

**中 = 猜测。这里收「还没验的猜想」——待对照的假设。**

- 旧 `原初\` 已归入这里：第一次做的判断样本，**不美化**——悬着的写悬着，证据/猜分开标。
- **验证方式**：分离单一变量 → 对照 → **验了才移走**（对了去 `正\复现经验\`，塌了去 `反\`）。
- 查不出缺哪块时，就放这——**别急着当正，先放中间等对照证据。**

## 格式

```
## 猜测 NNN：一句话
- 猜的是什么：
- 怎么验（单一变量）：
- 怎么推翻我：
- 验了之后去哪（正/反）：
- 当前状态（悬着/半验/已否）：
```
