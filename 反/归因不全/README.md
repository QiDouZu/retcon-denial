# 反：归因不全（更致命）

**这里收「归因不全」——当时真的以为全了，其实缺一块。它看起来完整，所以最像「曾经的正确」。**

- **单一归因**：错得清楚，**你知道反例在哪**。
- **归因不全**：**你连反例在哪都不知道**——缺口没进过场，所以查无可查。
- **辩证法框架验证的就是这个**：不是问「你哪条错了」，是问「你当时为什么以为它对」。

## 入口

- [`对照表.md`](对照表.md)：每条反例的「过程里错在哪 → 后来结果 → 判定」，**塌=曾经、悬=猜测、对=当前**。

## 收录格式

```
## 缺块 NNN：一句话
- 曾经以为（完整的样子）：——它为什么自洽、为什么当时觉得全了
- 后来露出缺的那块：
- 缺的是哪一层（因子/变量/前提/视角）：
```
