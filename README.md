# 回溯性重构：正、反、中

> **肯定和否定都是参考，只是各自得到的结果不一样。**
> **这个仓库装三样东西：正（当前已知的衍生）· 反（归因为单的参考）· 中（未判断的对照）。**
> **本质：把「回溯性重构」里「判断」那一步拆开用**——正反不是结论，是框架；中间态是常态。

---

## 三条目录

| 目录 | 放什么 | 是什么 |
|---|---|---|
| `正\` | **正确**：当前所有已知的衍生——**从错误里长出来的**，不是自证对的 | 参考之一 |
| `反\` | **反面**：归因为「单」——**单一变量的否定**，当参考框架用 | 参考之一 |
| `中\` | **中间**：未判断的——**分离错误、做单一变量对照**，用来丰富数据库 | 常态 |

**旧目录对应**：`否定\`→`反\`（+ 原假设→哪里塌→反例）；`反例\`→`反\`（单变量归因）；`过程\`、`原初\`→`中\`（未判断的样本与过程）。

## 为什么正反都是参考，中间的才是常态

- **平衡**：正和反都只是**参考**——**各自得到不一样的结果**，谁也不是终审。
- **正的来源**：**正确 = 当前所有已知的衍生**——**是根据错误来的**，每一条「现在对的」背后都踩着一条「以前以为对的」。
- **反的归因**：**反面 = 归因为「单」**——**只说「这一条变量错了」**，不扩展到整条判断，**当参考框架之一**收着。
- **中间**：**未判断**——**分离错误、做单一变量对照**，**能不能丰富数据库，是它唯一的问题**。
- **学习本身就是推翻**：池子都不完全 → 「原本对的」会被推翻 → 推翻的是**曾经对的**，不是错的。找的是**过程错在哪**。

## 判断拆开用（回溯性重构）

```
当时以为正 ── 过程（全程，不是头尾）
        │
        ├─ 中间：分离出单一错误变量 → 对照 → 未判断 → 进数据库
        │
        ├─ 反：这一条变量错了（归因为单，参考）
        │
        └─ 正：当前已知的衍生（从错误里长出来）
```

**拆开后每一格都能独立当参考**——正、反、中不是「对/错/待定」的判决，是**三种不同的用法**。

## 规则（精简：三条）

1. **评价只有两票**：正确，或者错误。**说错误必须附单变量反例**（归因为单），**没反例不算数**。
2. **必须保留过程**：**不是一段头尾**——中间怎么想、试了什么、在哪拐的弯，原样写。过程才是能被学的。
3. **匿名**：不写身份，写「这类判断」不写「这个人」。AI 不猜投稿人。

## 边界

- **不是审判谁对谁错**：这里只记「这条判断里哪个变量不成立」和「为什么」。
- **否定也不终审**：今天的反，明天可能被新的对照再拆——**这个仓库自己也是活的**。
