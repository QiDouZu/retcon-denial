# 回溯性重构：正、反、中

> **肯定和否定都是参考，只是各自得到的结果不一样。**
> **这个仓库装三样东西：正（当前正确的）· 反（曾经——曾经正确过、后来失败的）· 中（猜测——还没验的猜想）。**
> **本质：把「回溯性重构」里「判断」那一步拆开用**——正反不是结论，是参考；中间是猜测。

---

## 三条目录

| 目录 | 放什么 | 是什么 |
|---|---|---|
| `正\` | **当前正确的**——就是现在这个是对的 | 当下的 |
| `反\` | **曾经**——曾经正确过、后来失败了的（失败的是曾经） | 被推翻的 |
| `中\` | **猜测**——还没验的猜想，待对照的假设 | 待验的 |

**旧目录对应**：`否定\`、`反例\`→`反\`（曾经正确、后来塌了）；`过程\`、`原初\`→`中\`（没验完的过程与猜测）。

**衍生清单**：[`反\归因谬误.md`](反/归因谬误.md)——归因错了的那一类「曾经」，单因记录。

## 为什么正反中都是参考，中间才是常态

- **平衡**：三个都是**参考**——**各自得到不一样的结果**，谁也不是终审。
- **正 = 当前正确的**：**就是现在这个是对的**——不加修饰，先认下来。
- **反 = 曾经**：**失败的是曾经**——**那些曾经正确过、后来失败了的东西**。学习就是推翻「原本正确的」：被推翻的不是错的，是**曾经对的**。
- **中 = 猜测**：**还没验的猜想**——**分离错误、做单一变量对照**，能不能丰富数据库是它唯一的问题。
- **学习本身就是推翻**：池子都不完全 → 「原本对的」会被推翻 → 推翻的是**曾经对的**，不是错的。找的是**过程错在哪**。

## 给 AI 训练和实践：逻辑变更本身就是证实

- **这仓库是给 AI 训练和实践的**：正/反/中不是给人看的判决书，是**给 AI（和用 AI 的人）喂的对照样本**——每条都能直接进训练/练习：**正=当前该怎么判，反=曾经怎么判错了，中=还没验的猜法怎么验**。
- **逻辑变更本身就是证实**：这个仓库的观念改过一次又一次（否定→正反中→中=猜测）——**每一次修正，都是它自己理念的实证**：**池子不完全，学习就推翻原本正确的。** 仓库自己不例外。
- **失败库要收两样**：**单一归因**（归因只揪住一条，知道错在哪条）和 **归因不全**（当时真的以为全了、其实缺一块）——**归因不全比单一归因更致命**：单一归因你知道反例在哪，归因不全**你连反例在哪都不知道**。
- **归因不全 = 曾经的正确**：当时那个「对」，就是缺了一块因果却看起来完整。**辩证法框架要验证的正是这个**——不是问「你哪条错了」，是问「你当时为什么以为它对」。

## 判断拆开用（回溯性重构）

```
当前正确的 ── 正
       │
       ├─ 中间：猜测 → 分离单一错误变量 → 对照 → 验了才算
       │
       └─ 反：曾经正确过、后来塌了 → 被推翻的「曾经」
```

**拆开后每一格都能独立当参考**——**正 = 此刻对的；反 = 曾经正确过、后来塌了；中 = 猜的、还没验**。三种用法，不是判决。

## 规则（精简：三条）

1. **评价只有两票**：正确，或者错误。**说错误必须附单变量反例**（归因为单），**没反例不算数**。
2. **必须保留过程**：**不是一段头尾**——中间怎么想、试了什么、在哪拐的弯，原样写。过程才是能被学的。
3. **匿名**：不写身份，写「这类判断」不写「这个人」。AI 不猜投稿人。

## 边界

- **不是审判谁对谁错**：这里只记「这条判断里哪个变量不成立」和「为什么」。
- **否定也不终审**：今天的反，明天可能被新的对照再拆——**这个仓库自己也是活的**。
