# 否定是更有价值的那一半

> **肯定告诉你「对」，否定告诉你「为什么以前以为对」——后者才能改命。**
> 这个仓库专门装**否定**：哪里错了、为什么错、错的那条反例长什么样。
> **还有「原初的那一块」**：我学过、判断过、后来被推翻过的过程，原样开源——**让别人来验证我是对是错。**

---

## 这里放什么

| 目录 | 放什么 |
|---|---|
| `否定\` | 「我错了」的记录：**原假设 → 哪里塌了 → 反例**（为什么错比错本身重要） |
| `反例\` | 具体反例——**一条反例比十条正确案例更能纠正一个模型** |
| `过程\` | 学过的过程原样白盒：**我怎么想的、错在哪、被什么推翻**（可引用部分原话，匿名） |
| `原初\` | **原初的判断样本**：艺术鉴赏（审美）等判断，从第一次做就留着，**不美化成「早就想对了」** |

## 为什么专收否定

- **肯定只加固、否定才纠正**：人从「认对了」学不到多少，从「原来认错了」学得最多。
- **错得越具体，价值越大**：不是「我错了」，是 **「我拿 4/5 分当钩子——陌生人根本不关心分数」**——这样的否定才能教下一个。
- **反例是活教材**：反例放在这，**下一个人拿它对照自己**，少踩同一脚。

## 池子都不完全：学习就是推翻「原本正确的」

- **任何池子都不完全**：案例、数据、我自己的判断——**再全也缺一块**。所以**学习不加固对的东西，而是否定「原本以为对的」**——**被推翻的不是错的，是曾经对的。**
- **找的是「过程错在哪」**：不是审判谁错了——**是回到过程里，看哪一步当时觉得对、其实走歪了。**
- **真正有价值的是正反对照**：**同一件事的「当时以为是正」和「后来对照出反」，并排放**——只有反例没正例，看不出错在哪；只有正例没反例，看不出哪天真会翻。
- **中间的才是常态**：大多数判断**不是纯对纯错，是悬在中间**——半对、待验、两面都有理。**中间态最值得记**：它才是学习真正发生的现场。

## 怎么用这个仓库

1. **投稿**：匿名投一条「我本来以为 X，后来发现其实是 Y」+ 反例原文（不写身份）。
2. **验证**：拿这的反例去套你正在学的——**套得上，说明你也可能踩了；套不上，来推翻我们。**
3. **引用**：可以引用**部分原话**（匿名），引「当时怎么想」的那部分。

## 怎么评价（只有两票）

> **更新评价只有两个选项：正确，或者错误。**
> **说「错误」必须附反例**——**没有反例的「我觉得你错了」不算数。**

```
正确 ── 记下（加固）
错误 + 反例 ── 记下反例 → 进反例库 → 筛选 → 判这条该不该翻
```

- **「错误」是唯一能推翻东西的票**：**所以它必须带证据**——反例没写清（什么场景、怎么发生的），这票作废。
- **评测完先筛，再进库**：不是每条反例都立刻翻案——**先筛「这条反例站不站得住」，站得住的才进库当对照**。
- **筛选仍然是学习**：筛的过程本身在教判断「什么才算反例」。

## 反例库是照镜子，不是点名

**反例存进来，不是判谁错，是给你对照：**

> **「我有没有犯这个错？」**

- 拿反例逐条对：**对得上 → 你大概率犯过同样的错；对不上 → 你这条判断先别急着信，再看看**。
- **反例越大白话越好用**：能让你一句话照见自己的反例，比长篇分析值钱。

## 匿名规则

- **评价也匿名**：投票只说「正确 / 错误 + 反例」，**不写你是谁**——没人知道哪张票是谁投的。
- 不写真实姓名、联系方式、住址、单位；**写「这类判断」不写「这个人」**。
- AI 不猜投稿人是谁，不反向追踪。

## 边界

- **不是审判谁对谁错**：这里只记「我这条判断塌了」和「为什么」，**不是给人定罪**。
- **否定也不终审**：今天的否定，明天可能被新的反例再否定——**这个仓库自己也是活的。**
