# 经验 001：立命用方便——单文件可调用，别拆

## 条件

改一个正在被用的工具（画笔、语音、面板、流水线）——**改之前它已经在用了**，不是从零造。

## 动作

1. **原生**：能原生 GUI 的就用原生（画笔走小画家，别塞进面板）。
2. **不拆**：不把脚本拆成十几个模块——**拆得漂亮不等于价值高**。
3. **可调用**：都做成「能连这个文件就调用」——工具、水印、流水线、API 全从这一处调。
4. **不加功能、不改界面**：原样换掉实现，外观保持旧工具的样子。

## 结果

- 用户能直接用：拖个文件/喊一声就出效果，**0 报错**。
- 用的人（和用它的 AI）不用学新结构——**入口没变**。

## 边界（什么情况下不成立）

- **新需求出现时，别往这个入手里加**——先问他（他常回「不加了，有点烦」）。加功能就破坏「不加界面」这一条。
- **不是所有好结构都能拆**：结构是手段，**调用方便才是目的**——目的没变，手段就不许换。
