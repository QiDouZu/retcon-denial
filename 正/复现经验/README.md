# 正：复现经验

**正 = 当前正确的。这里收「可复现的成功经验」——不是故事，是下次还能得到同样结果的链条。**

## 收什么

**一次一条，按「条件 → 动作 → 结果 → 边界」写：**

- **条件**：什么场景下它成立（换场景可能失效，必须写）
- **动作**：当时具体做了什么（不是「我努力了」，是「我做了哪一步」）
- **结果**：可复现的产出/变化
- **边界**：**什么情况下它不成立**——失败条件不写，这条经验就是待验的猜测

## 为什么它在这

- 每一条「现在对的」，背后都踩着一条「曾经对的」——**能说清从哪个错误里长出来更好**。
- **能复现的才算正**：只对一次的叫运气，能重复的才叫经验。

## 格式

```
## 经验 NNN：一句话
- 条件：
- 动作：
- 结果：
- 边界（什么情况下不成立）：
- 来源（可选，从哪个「曾经」来的）：
```
